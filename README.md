# 足関節モーメントラボ

力学学習シリーズ第4弾。床反力とCOPを操作して、足関節まわりの外的モーメント、姿勢を保つために必要な底屈モーメントと筋張力を学びます。

## 起動

[足関節モーメントラボを起動する](https://keizoliberalartslab.github.io/P004_AnkleMoment/)

配布・共有用URL：https://keizoliberalartslab.github.io/P004_AnkleMoment/

インストールやログインは不要です。このURLを共有してください。
ダウンロードして使う場合は `index.html` をブラウザで開いてください。

## 操作

- 床反力：300〜1000 N（初期値600 N）
- COP：足関節直下の0 cm〜つま先の20 cm（初期値10 cm）
- 数値入力・スライダー、COPのプリセット、図上のCOPドラッグに対応
- COPハンドルはキーボードの矢印キー・Home・Endでも変更可能
- 床反力の青矢印は床反力に比例して長さを変更
- 赤い筋張力矢印は計算した筋張力に比例して長さを変更
- 床反力による背屈モーメントと必要な底屈モーメントを、同じ縮尺の半透明中抜き矢印で表示

## 計算

レバーアーム d = COP位置(cm) / 100。
外的モーメント M = 床反力 F × d。
静的釣り合いに必要な底屈モーメントの大きさも M。
筋側の有効モーメントアームは、ユーザー指定の5 cm固定。
必要な筋張力 T = M / 0.05。

床反力1000 N・COP20 cmでは、M = 200 N·m、T = 4000 N。
COPが直下の場合はM = 0、T = 0。

## モデルと表示

鉛直床反力のみの静的な平面モデルです。足部の自重・慣性・他の筋の作用は省略します。筋張力はこの釣り合いモデルに必要な値であり、実測筋力の推定ではありません。

床反力矢印と筋張力矢印は共通の縮尺（1000 Nで75図座標）で表示し、力の比が長さの比になります。筋張力の数値は赤矢印の先端の上に表示します。両モーメント矢印のサイズは共通の規則（最大値に対する平方根に比例）で変化します。モーメントが0の場合、中抜き矢印と筋張力矢印は非表示です。

参考として添付されたスライドの色分けを踏襲しています。スライド自体はアプリに含めていません。
